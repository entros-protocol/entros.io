Near-term engineering focuses on the live human-presence and consent firewall for Voice-AI and autonomous MCP agents. None of the items below are live as commercial SLAs today.

## Blind voice anti-spoofing and codecs

Production validation enforces the pinned `v2 AASIST-L` model (`131.0 ms` p95 latency, `495.5 MB` RSS, `61.84%` catch rate on unseen neural TTS). Active ML work trains and evaluates a distilled successor under preregistered blind holdout gates.

Evaluation covers `webrtc_16k` and `telephony_8k` codec profiles, unseen neural TTS generators, live voice conversion, and partial splices. Raw un-denoised audio enters the detector without upstream neural denoisers.

## Hosted Voice Defense API and VPC sidecar

The upcoming Voice Defense API will expose streaming WebSocket and HTTP endpoints for live Voice-AI channels. Scoring will run in memory with zero disk persistence and zero default voiceprint database.

The service will emit calibrated verdicts, operating-profile metadata, and explicit `insufficient_signal` abstention states. A paired INT8 CPU ONNX VPC sidecar will serve teams that keep audio inside their own infrastructure.

## Web2-first AgentPermit v2

Active SDK work extends pure-MIT `@entros/verify/mcp` beyond Solana devnet wallets. Planned additions include OIDC and JWT principals, hardware Passkey and WebAuthn step-up approvals, signed voice-liveness binding, tamper-evident compliance receipts, and a Python SDK.

`@entros/verify/solana` stays available as an optional subpath export for Solana devnet compatibility.

## Design-partner pilots

Initial pilots will deploy real-time voice liveness and action-bound MCP authorization on live customer traffic. Pilot measurements will calibrate operating points and deployment guides.

## Paused Solana mainnet gates

Pre-mainnet Solana milestones stay paused pending paying customer demand for optional on-chain audit anchoring:

- Public multi-party trusted-setup ceremony for the Groth16 verifier
- External security audit of `entros-anchor`, `entros-verifier`, and `entros-registry`
- Mainnet program deployment and validator network research
- Native mobile client builds
