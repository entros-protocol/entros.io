## Token

$ENTROS is a fixed-supply SPL mint created on an EasyA Kickstart bonding curve on July 30, 2026. Mint authority and freeze authority are revoked, and the mint carries zero Token-2022 extensions. The devnet Entros Anchor uses a separate Token-2022 mint with the `NonTransferable` extension, so the two assets share no code or state.

$ENTROS has zero coupling to Entros security products, API billing, or engineering roadmaps. Earlier concepts for validator staking, capacity tiers, and token governance remain unbuilt and paused alongside Solana mainnet. See [Token Record](/token) for the mint address and public Streamflow lockups.
